# Privacy Policy

This Privacy Policy explains how the **Custom Increment ID for Magento 2** extension handles user data and ensures privacy compliance.

## 1. No Personal Data Collection

The extension does **not collect, store, process, or transmit** any personal or sensitive customer information. It functions solely within the Magento backend environment and performs only the following:

- Generates custom increment IDs for **Orders**, **Invoices**, **Shipments**, and **Credit Memos**
- Applies prefix settings and starting sequences configured by the store administrator
- Operates without any connection to external servers or APIs

## 2. No External Communication

This extension does **not communicate with third-party services**, cloud platforms, or external databases. All operations are executed **locally within the Magento system**.

## 3. GDPR & Privacy Compliance

Because the extension does not access or interact with any personally identifiable information (PII), it is considered **GDPR-compliant** and meets modern data privacy standards.

- No cookies
- No customer profiling
- No background tracking
- No third-party sharing

## 4. Scope of Use

This extension is intended for use by Magento administrators to customize how increment IDs appear for internal business or legal formatting purposes (e.g., adding prefixes like `INV`, `CRD`, or country codes). It does **not** alter order content, customer data, or any marketing activity.
