# Privacy Policy — Laith Almasri Magento 2 Extensions

**Effective Date:** May 2026
**Developer:** Laith Almasri
**Contact:** Laith.k.m@gmail.com

This Privacy Policy applies to all Magento 2 extensions developed and published by Laith Almasri on the Adobe Commerce Marketplace and any other distribution channels.

---

## 1. General Principle

All extensions developed by Laith Almasri are built with a privacy-first approach. As a general rule, our extensions do not collect, store, process, or transmit any personal or sensitive information belonging to store owners, administrators, or end customers.

---

## 2. No Personal Data Collection

Unless explicitly stated in a specific extension's documentation, our extensions do not:

- Collect customer names, emails, addresses, or payment information
- Store personally identifiable information (PII) in external databases
- Track customer behavior or browsing activity
- Profile customers for marketing or analytics purposes
- Access sensitive order or account information beyond what is required for core functionality

---

## 3. No External Communication

Unless explicitly stated in a specific extension's documentation, our extensions do not:

- Communicate with third-party servers, APIs, or cloud platforms
- Send data outside the Magento installation
- Connect to remote databases or storage services
- Phone home for license validation or usage statistics
- Load external scripts or tracking pixels

---

## 4. Data Stored Locally

Any data created or modified by our extensions — including configuration settings, generated files, log entries, or cached records — is stored exclusively within the Magento installation on the store owner's own server.

This data is fully under the control of the store administrator and is never transmitted externally by the extension.

---

## 5. Extension-Specific Notes

Some extensions may store additional data locally as part of their functionality. This is documented per extension as follows:

| Extension | Local Data Stored |
|---|---|
| LlmsTxt AI Visibility | Configuration settings, generated llms.txt files, AI bot visit logs stored in local database table |
| Custom Increment ID | Prefix configuration and sequence counters stored in Magento config |
| *(future extensions)* | Documented in each extension's README |

None of this data is ever transmitted outside the store's server environment.

---

## 6. GDPR & Privacy Compliance

All extensions are designed to be GDPR-compliant by default:

- No cookies set by any extension
- No customer profiling
- No background tracking or telemetry
- No third-party data sharing
- No external API calls without explicit disclosure
- Full data ownership remains with the store administrator

---

## 7. Admin-Only Operations

All extensions operate exclusively within the Magento admin panel and server environment. They do not expose frontend interfaces that interact with customer personal data, payment information, or sensitive records beyond their documented functionality.

---

## 8. Third-Party Services

If a specific extension integrates with a third-party service such as an external API, this will be clearly disclosed in that extension's documentation and on its Marketplace listing. In such cases, the third party's own privacy policy also applies to data shared with that service.
